# Perception MCP

Perception gives AI agents access to digital asset narrative intelligence through 31 MCP tools. Search and analyze reporting, topics, entities, sentiment, and market narratives across thousands of curated media sources and 15 years of history.

## Connect

**Endpoint:** https://mcp.perception.to/mcp

Perception uses OAuth. Your MCP client will open a browser window so you can sign in and authorize access.

For clients that accept a remote MCP configuration:

~~~json
{
  "mcpServers": {
    "perception": {
      "url": "https://mcp.perception.to/mcp"
    }
  }
}
~~~

## What agents can do

- Search digital asset reporting across thousands of curated media sources
- Track topics, entities, narratives, and sentiment
- Compare companies, protocols, assets, and market themes
- Analyze 15 years of historical coverage
- Monitor current media attention and narrative shifts
